=================
Function Features
=================

This section provides guides and tutorials for building IBM Quantum Functions (formerly Qiskit
Functions). Learn how to create, test, and deploy functions with various features and
capabilities.

Functions can be uploaded as Python source code and executed on remote compute resources. These guides cover both basic usage patterns and experimental features.

.. note::

   Most of the tutorials below run against a local **Ray** cluster; see :ref:`concepts` for how
   Ray relates to **Fleets**, and :ref:`fleets_tutorials` for a Fleets walkthrough.
